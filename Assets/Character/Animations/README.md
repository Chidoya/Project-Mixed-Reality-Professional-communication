# Animations

Put the Mixamo animations here (downloaded once on the default Y Bot):
FBX for Unity, Without Skin, 30 fps.

Recognised file names (spaces and case are ignored):

| File | Animator state |
| --- | --- |
| Idle.fbx | Idle |
| Talking.fbx | Talking |
| Sitting Idle.fbx | Sitting |
| Laying Idle.fbx / Lying Idle.fbx | Laying |
| Sad Idle.fbx | Sad |
| Angry.fbx | Angry |
| Crying.fbx | Crying |

Then run **ProCommVR > Characters > Setup** in Unity. All 18 characters share these clips
through Humanoid retargeting.
